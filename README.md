# 🚗 Proyecto de ML No Supervisado del Tráfico en Asturias
### *Optimización del tráfico usando Machine Learning*  

## 📌 Descripción  
Este proyecto analiza el tráfico en el Principado de Asturias y aplica técnicas de **Machine Learning** no supervisado para agrupar con clustering, reducir dimensionalidad y detectar anomalías del tráfico, también crea un recomendador de rutas con clustering previo con el algoritmo Dijkstra.  

## 📚 Estructura del Proyecto  
```
📁 ProyectoTraficoAsturias
│-- 📓 traficoAsturias.ipynb   # Notebook de análisis exploratorio y ML 
│-- 📄 recomendadorRuta.py    # Recomendador de rutas con agrupamiento clustering
│-- 📊 trafico_asturies.csv    # Datos históricos de un instante
│-- 📊 trafico_asturies_dia.csv # Datos de tráfico de un día
```

## 🎯 Cómo Ejecutar
1⃣ Instalar dependencias con `pip install -r requirements.txt`.
2⃣ Ejecutar `python recomendadorRuta.py`.  

3⃣ Seleccionar la calle de origen y destino.  
4⃣ ¡Ya puedes ver la mejor ruta y visualizarla en el mapa!
